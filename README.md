# ✦ AstroSpark
### Ignite Your Universe.

**AstroSpark** is a cosmic-themed new-tab experience that transforms your browser's empty starting page into a personal space dashboard.

Explore the universe, discover breathtaking NASA imagery, stay productive, and personalise your digital environment — all from one place.

---

## 🌌 Overview

AstroSpark combines astronomy, productivity, and personalisation in an immersive space-inspired interface.

Instead of opening another ordinary new tab, step into your own little universe.

## ✨ Features

### 🚀 Cosmic Experience
- Immersive space-inspired interface.
- Animated stars, planets, and orbital elements.
- Live digital clock and dynamic greeting.
- Responsive design for different screen sizes.

### 🔭 NASA & Space Exploration
- **Astronomy Picture of the Day (APOD):** Discover astronomical images and explanations.
- Browse NASA imagery and space-related information.
- Explore celestial objects and fascinating facts.
- Access original NASA media and information where available.

### ⚡ Productivity Dashboard
- **Task Manager:** Add, complete, and delete tasks.
- **Focus Timer:** Stay focused with a dedicated timer.
- **Quick Notes:** Write and save notes directly in your dashboard.

### ⚙️ Personalisation
- Dedicated settings panel.
- Customisable display preferences.
- Clock format options.
- Search engine preferences.
- Audio and visual settings.
- Reduced-motion support.

### 🌍 Explore
- Interactive space exploration interface.
- Planetary information and facts.
- A visual representation of the Solar System.

## 🔑 NASA API Configuration

AstroSpark uses NASA's public APIs for astronomy-related content.

You can obtain an API key from:

https://api.nasa.gov/

Use the API key configuration expected by the project's JavaScript implementation.

**Important:** Do not commit private API credentials to a public repository. A key embedded in frontend JavaScript is visible to visitors, so use a secure backend proxy if you need to keep a credential private.
